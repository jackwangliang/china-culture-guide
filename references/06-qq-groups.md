# 06 — Finding and Joining QQ Groups

Use this reference for "how do I join a QQ group", 找群, 群号, group QR invites, verification messages and group etiquette. QQ remains strong among students, gamers, fandom communities, study groups and interest-based discussion — and unlike WeChat, it has **public group discovery**, which is exactly why it is the best first step for a foreigner looking for people to talk to.

**Never invent group numbers, group names or invite links in an answer.** They expire and change. Teach the search method instead.

## Before starting: get an account

1. Install QQ from an official app store. Some markets offer a QQ International edition with an English interface and built-in translation; availability, languages and features have changed over time, so check the current store listing rather than relying on old guides.
2. Register with a mobile number. International numbers are commonly supported for SMS verification, but this depends on the current app version and region — if an SMS does not arrive, see `08-getting-set-up.md`.
3. Some features may require identity verification. Use only the in-app official flow with your own documents; never buy an account, borrow someone's ID, or pay a stranger to "verify" you.
4. Set a neutral nickname and avatar. A profile with a clear, friendly self-description gets group applications approved far more often.

## Four ways to find a group

| Method | Steps | Notes |
|---|---|---|
| **1. Keyword search (best for beginners)** | 联系人 / liánxìrén ("Contacts") → 加好友 / 找群 or the person-plus icon → **找群 / zhǎo qún ("Find Groups")** → type a keyword → browse results | Search by group name or interest category; try several synonyms |
| **2. Group number** | In 找群, enter the 群号 / qún hào (a numeric group ID) → 搜索 / sōusuǒ ("Search") → 申请加入 / shēnqǐng jiārù ("Apply to join") | Get the number from a friend, a forum, an event poster or a video description — never from a paid "group list" seller |
| **3. QR code** | 扫一扫 / sǎo yī sǎo ("Scan") → scan a 群二维码 / qún èrwéimǎ (group QR code) → apply | Group QR invites commonly expire (often around seven days) and may stop working once a member limit is reached; ask for a fresh one |
| **4. Invitation** | A member adds you to the group | Requires someone you have already met — see `04-making-friends.md` |

Some QQ editions have presented a **Groups** panel with English interest categories (nightlife, travel, business, languages, music and similar) and a "Join a Group" flow where a group number is entered. This is useful context but is an edition-specific feature; verify it in the installed app instead of promising it.

## Keywords that find real communities

Combine an interest noun with a community suffix: 交流 (jiāoliú, exchange/discussion), 学习 (xuéxí, study), 爱好者 (àihàozhě, enthusiasts), 打卡 (dǎkǎ, daily check-in), 新手 (xīnshǒu, beginners), 备考 (bèikǎo, exam prep).

| Interest | Search terms |
|---|---|
| Language exchange | 英语角 / 语伴 / 中英互换 / 中文学习 交流 |
| Mandarin exams | HSK 备考 / 汉语 学习 |
| Photography | 摄影 交流 / 街拍 爱好者 |
| Tea | 茶 交流 / 茶道 学习 |
| Traditional dress | 汉服 交流 / 国风 爱好者 |
| Chinese history | 历史 爱好者 / 文物 交流 |
| Cooking | 家常菜 交流 / 烘焙 打卡 |
| Games / anime | [game or series name] + 交流 / 同好 |
| Fitness / wellness | 太极 交流 / 跑步 打卡 |
| City life | [city name] + 生活 / 同城 |

Search both the Chinese term and, once, the English name — Chinese-language groups rarely use English titles.

## Reading a group before applying

On the group profile, check: 群名称 (name), 群简介 / 群公告 (description / announcement), member count and activity, 群标签 (tags), whether 加群验证 (join verification) is required, and whether the group is 不可搜索 (not searchable / private). A group with a clear announcement, recent messages and a written rule set is a much better bet than a huge silent group.

**Skip any group that** charges an entry fee, asks for passport or bank details to join, promises exam answers or "guaranteed" earnings, or is mostly advertising and resale links.

## The verification message

Many groups require 验证信息 / yànzhèng xìnxī ("verification message") and an admin (管理员 / guǎnlǐyuán) approves it. Write two short lines in Chinese, with one line of English if the group is a language-exchange group:

> 你好！我来自法国，正在学中文，对摄影很感兴趣。希望加入交流学习，谢谢！
> Nǐ hǎo! Wǒ láizì Fǎguó, zhèngzài xué Zhōngwén, duì shèyǐng hěn gǎn xìngqù. Xīwàng jiārù jiāoliú xuéxí, xièxie!
> "Hi! I'm from France, learning Chinese and interested in photography. I'd like to join and exchange ideas. Thanks!"

More templates in `09-phrasebook.md`. Replace the country and interest. Do not paste the same message to twenty groups — generic applications are routinely rejected. If declined, wait and try a different group; do not re-apply repeatedly.

## After joining

1. Read 群公告 / qún gōnggào ("Group announcement") and 群规 / qúnguī ("Group rules") first.
2. Set your 群名片 / qún míngpiàn ("Group nickname") to something readable, e.g. `Alex | France | beginner Chinese`.
3. Watch for a day to learn the tone, then post a two-line self-introduction.
4. Turn on 消息免打扰 / xiāoxī miǎn dǎrǎo ("Do Not Disturb") if the group is busy; use 置顶 / zhìdǐng ("Pin") for one group you care about.
5. Respect the time zone: most members use China Standard Time (UTC+8). Do not expect replies at 3 a.m. their time.
6. No advertising, no mass private messages to members, no long voice notes without asking, no reposting private chat screenshots, no spam of links or unverified claims.

## QQ groups vs WeChat groups

| | QQ 群 | 微信群 |
|---|---|---|
| Discovery | Public search by keyword / group number | No public search; invite or QR only |
| Size and tools | Larger groups, files, albums, announcements, admin roles | Smaller, tied to your contacts |
| Typical use | Interest, study, gaming, fandom, students | Friends, family, work, close communities |
| Best for a foreigner | **Start here to meet people** | Use after a connection exists |

A natural path: find a QQ group around a hobby → have a few good public exchanges → move a one-to-one conversation to WeChat only if both people want it.

## Troubleshooting

| Problem | Likely cause / fix |
|---|---|
| No results | Keyword too narrow or in English; shorten it, add 交流 / 爱好者, try a synonym |
| "需要验证" / verification required | Write the short bilingual message above; wait for an admin |
| "群已满" / group full | Look for a sister group or ask politely for another |
| Group not searchable | Private group — request an invite from a member |
| QR code expired | Ask for a new code; they are time-limited by design |
| Application declined | Normal; try another group, do not re-apply in a loop |
| Too many notifications | 消息免打扰; do not leave five groups at once in frustration |
| Removed from group | Usually a rule violation; ask an admin politely and learn the rule |

## Safety recap

No entry fees, no paid "guaranteed group entry", no investment or 刷单 (fake-order job) schemes, no private lending, no sharing verification codes, no clicking shortened links from strangers. See the safety checklist in `04-making-friends.md` and `10-accuracy-sources-and-scope.md`.

Open 找群, search two keywords from the table, read three group announcements, and send **one** well-written verification message to the group that looks most active and welcoming. Then wait — approval is done by a human admin.
