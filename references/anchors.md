# Anchors — the small, stable skeleton

This is the **only** file that stores reusable cultural facts. It exists because some scaffolding is shared by hundreds of questions: a rough chronology, a handful of concepts, and the typical ways explanations go wrong.

**Maintenance rule:** this file must not grow with new questions. A new user question about a new object does **not** earn an entry here. Add a worked case in `cases/` or refine a lens in `framework.md` instead. If this file starts approaching a encyclopaedia, the architecture has regressed.

**Role under the search gate:** this file is a scaffold for **generating search queries and organising retrieved evidence**. It is **not an offline answer source**. If live search is unavailable, follow the NO-SEARCH CONTRACT in `evidence.md` — do not build an explanation from the tables below. Anchors can tell you *what to ask about*, never *what happened*.

Everything below is **orientation, not evidence**. For any specific date, quotation or causal claim, follow `evidence.md` and verify.

## 1. Rough chronology

Dates before c. 841 BCE are approximate. Use "traditionally dated" or "archaeologically attested", never exact.

| Period | Approx. | One line |
|---|---|---|
| 夏 Xia | traditionally c. 2070–1600 BCE | Known mainly from later texts and ongoing archaeology |
| 商 Shang | c. 1600–1046 BCE | Oracle bones; earliest mature Chinese writing; bronze ritual vessels |
| 周 Zhou | 1046–256 BCE | Classical philosophers; 礼 ritual order |
| 秦 Qin | 221–206 BCE | First unification; standardised script and measures |
| 汉 Han | 206 BCE–220 CE | Silk Road; 汉字 and 汉 as names for script and majority ethnicity |
| 三国 / 晋 / 南北朝 | 220–589 CE | Buddhism, calligraphy, new crops and oils, high seats begin to appear |
| 隋 / 唐 Sui–Tang | 581–907 CE | Cosmopolitan cities; chairs and high tables; shared-table dining emerges |
| 宋 Song | 960–1279 CE | Printing, commercial urban life, restaurants; iron cooking pans spread widely |
| 元 / 明 / 清 Yuan–Ming–Qing | 1271–1912 CE | New oil crops and fuels, regional cuisines, mature wok technique |
| Modern period | 20th c. onward | Covered here only through heritage, museums and everyday life |

Never treat a dynasty change as an overnight change in daily habits.

## 2. Technology and everyday-life nodes

Useful as a first hypothesis about *which prerequisites* a practice needed. All need verification before being asserted.

| Node | Approx. | Why it matters |
|---|---|---|
| 陶鼎 / 陶釜 earthenware cauldrons | Neolithic | Boiling and steaming; the vessel mediates water and fire |
| 青铜鼎 bronze ritual cauldrons | Shang–Zhou | Elite, ritual, status-graded (列鼎而食); not everyday cookware |
| Cast iron implements | Warring States–Han | Iron spreads from agricultural tools toward cookware |
| 植物油 plant oils (胡麻/芝麻 sesame) | Han–Wei–Jin | Oil becomes an affordable heat-transfer medium; animal fat was earlier norm |
| 高桌椅 high tables and chairs | 5th c. onward, common by Tang | Sitting posture changes; individual 分餐 shifts toward shared 合食 |
| Thin-walled iron pan 铁锅 | widely from Northern Song onward | Makes high-heat, fast tossing practical in ordinary kitchens |
| Coal, improved stoves, new oil crops | Ming–Qing | Stronger, more controllable heat; techniques subdivide |

The five-stage distinction from `framework.md` applies to **every** row: first appearance, first record, standardisation, popularisation, modern revival. "Exist in a text" ≠ "common in homes".

## 3. Core concepts (20)

| Term | Pinyin | Plain gloss | Do not misuse |
|---|---|---|---|
| 阴阳 | yīnyáng | Complementary, interdependent poles | Not good vs evil |
| 五行 | wǔxíng | Five phases: wood, fire, earth, metal, water; a correlative classification | Not a causal engine that "produced" a cooking technique |
| 水火相济 / 既济 | shuǐ huǒ xiāng jì / jìjì | "Water over fire, already completed" — the classic cooking metaphor of opposites mediated by the vessel | Often loosely called "五行相生"; check the actual classical phrasing |
| 气 | qì | Transformative breath / vital process | Avoid vague mystical uses |
| 火候 | huǒhòu | Heat level and timing; a technical term borrowed from alchemy | It is a craft concept before it is a metaphor |
| 鼎 / 镬 / 釜 | dǐng / huò / fǔ | Ritual cauldron / large cauldron / pot | Different objects, different eras |
| 礼 | lǐ | Ritual propriety, role-based conduct | Not simply "etiquette" |
| 和 | hé | Blending into harmony, of flavours or people | Not mere agreement |
| 面子 | miànzi | Social standing; avoidance of public embarrassment | Not vanity |
| 人情 | rénqíng | Long-term reciprocal obligation | Not a bribe |
| 孝 | xiào | Respect and care for elders | Not blind obedience |
| 节气 | jiéqì | The 24 solar terms | Not the same as lunar festivals |
| 生肖 | shēngxiào | 12-year animal cycle | Not astrology in the Western sense |
| 谐音 | xiéyīn | Homophone-based auspicious or taboo associations | Folk custom, not a rule everyone follows |
| 箸 / 筷 | zhù / kuài | Old and current name for chopsticks | The renaming is Ming-era and regional |
| 分餐 / 合食 | fēncān / héshí | Individual serving / shared table | Shared dining is roughly a thousand years old, not "ancient" |
| 家常 | jiācháng | Home-style, everyday | Not a regional cuisine |
| 锅气 / 镬气 | guō qì / huò qì | "Wok hei", the aroma of high-heat tossing | A restaurant ideal, not a household requirement |
| 儒 / 道 / 佛 | Rú / Dào / Fó | Confucian, Daoist, Buddhist traditions | They coexist; never say "Chinese thought is..." |
| 宗族 | zōngzú | Lineage / clan organisation | Vastly stronger in some regions than others |

## 4. Object genealogies (skeletons only)

- **Cooking vessels**: 鼎 (ritual boiling) → 镬 / 釜 (cauldrons) → 铁锅 (thin iron pan) → modern wok. Each enables a different relation between heat, oil and time.
- **Eating tools**: 匕 (bone spoon, Neolithic) and early forks → 箸 (documented by Shang, archaeological copper examples by Spring and Autumn) → 筷 (Ming renaming). Food cut small in the kitchen is the usual explanation for why table knives disappeared from the table.
- **Posture and furniture**: 席 (floor mat) → 胡床 / 凳 / 椅 (high seats) → 高桌 (high table). This is the material cause usually given for the shift from individual to shared dining.
- **Table**: 食案 (small individual tray) → large shared table, common by Song.

Each arrow is a **hypothesis about enabling conditions**, not a proof of causation. Verify with the lenses — and with sources.

## 5. Eight recurring error patterns

Use this list as a checklist before publishing an answer.

1. **Presentism** — assuming today's meaning, tool or practice existed unchanged in the past.
2. **Single cause** — crediting one idea, crop or invention for a complex practice.
3. **Backwards causality** — claiming a philosophy caused a technique, when the technique likely came first and the philosophy generalised from it.
4. **Over-generalisation** — one region, dynasty, class or generation presented as all of China, for all time.
5. **Legend as history** — a folk etymology or a later text treated as contemporary evidence.
6. **Translation equivalence** — assuming "stir-fry", "dialect", "face" or "dragon" map cleanly onto 炒, 方言, 面子, 龙.
7. **Invention vs popularisation** — the earliest record used as proof that everyone did it.
8. **Internet elaboration as classical doctrine** — a modern symbolic reading quoted as if it came from an ancient classic.

## 6. When anchors are not enough

If a question names an object, text or event with no anchor here, do **not** add one. Run the generic path in `framework.md`, which **requires live search**, and answer from the evidence. If search is unavailable, use the NO-SEARCH CONTRACT in `evidence.md`: the anchors and lenses become a list of questions to check later, not an answer. The skeleton is meant to be small enough to stay correct.
